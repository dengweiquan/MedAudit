# MedAudit 0.25.0-m23

首个公开发布。医疗权限审计平台：对数据库 / 操作系统 / 中间件 / HTTP API
四类对象做只读权限采集与规则评估（65 条规则），关联分析（权限图、提权
路径、有效权限、跨期漂移），Word 报告「审计 → 整改 → 复检」闭环，单院
部署。

## 安装包（x86_64，零外部依赖）

- `medaudit_0.25.0+m23-1_amd64.deb` — Debian / Ubuntu：
  `sudo apt install ./medaudit_0.25.0+m23-1_amd64.deb`
- `medaudit-0.25.0-m23.1.x86_64.rpm` — RHEL / Rocky / AlmaLinux / CentOS：
  `sudo dnf install ./medaudit-0.25.0-m23.1.x86_64.rpm`

安装后：编辑 `/etc/medaudit/medaudit.env` 填写本站医院
（`MEDAUDIT_SITE_HOSPITAL_ID` / `_NAME`），`systemctl restart
medaudit-server`，浏览器打开 `http://<服务器>:8080`（初始账号 admin，
首登强制改密）。证据加密密钥在安装时自动生成并写入该 env 文件，请备
份。

## 本版内容

- **M23 — 工程师 CLI 全面改版**：`ma` 命令族（HP-UX LVM 风格，一命令
  一事、位置参数、单字母旗标）替代旧 medauditctl；采集器命令行同歩简
  化。
- **M24 — 系统包安装**：deb / rpm 原生包（systemd 单元、系统用户、配
  置模板、密钥首装生成、干净卸载），替代手工拷二进制部署。
- 此前里程碑：M19 Linux 服务覆盖、M20 用户管理、M21 HP-UX 支持、
  M22 基线一键豁免（问题页逐项推导加入基线）、M17 客户面与本站模式、
  M18 专业版 Word 报告。
