# MedAudit 0.26.0-m25

维护版本：Tomcat TLS 协议解析补全、Linux root_mismatch 误报修复、
打包版本串参数化。

## 安装包（x86_64，零外部依赖）

- `medaudit_0.26.0+m25-1_amd64.deb` — Debian / Ubuntu：
  `sudo apt install ./medaudit_0.26.0+m25-1_amd64.deb`
- `medaudit-0.26.0-m25.1.x86_64.rpm` — RHEL / Rocky / AlmaLinux / CentOS：
  `sudo dnf install ./medaudit-0.26.0-m25.1.x86_64.rpm`

安装与本站医院设置同前版（交互安装时提示输入本站医院 ID 与名称；
或事后编辑 `/etc/medaudit/medaudit.env` 再重启服务）。浏览器打开
`http://<服务器>:8080`（初始账号 admin，首登强制改密）。

## 本版内容

- **Tomcat 采集器解析 SSLHostConfig**：`mw.tomcat.tls_weak` 此前只识别
  APR 时代的 `SSLProtocol` 属性，Tomcat 9 主流的
  `<SSLHostConfig protocols="…">` 写法与 JSSE 的 `sslProtocol` 属性
  均未解析，弱 TLS 配置会漏报。本版按
  SSLHostConfig > sslProtocol > SSLProtocol 的优先级取生效协议配置，
  规则口径不变（协议配置为空时不臆测）。
- **os.linux.root_mismatch 误报与文案修复**：`user@0.service` 等以数值
  uid 报告配置用户的单元（如经 systemctl 返回 `User=0`）此前会被误判
  「配置用户 0 与 EUID=0 不一致」。本版将数值 `0` 与 `root` 等同判定，
  并重写命中文案（含服务单元名、配置用户与进程名）；采集事实新增
  `unit` 属性，整改脚本可直接指名单元。规则版本升至 2，存量事实包
  重新评估即受益。
- **打包版本串参数化**：版本号改为单一入口——`package.sh <版本>` 与
  `build-packages.sh <产物目录> <版本>` 同值传入，deb/rpm 的版本字段
  与文件名全部按规则派生，`control`/`spec` 不再硬编码版本号；
  `package.sh` 增加护栏，程序版本常量与打包版本不一致时拒绝出包。
