# MedAudit 0.37.0-m37

医疗系统权限审计平台（数据库 / 操作系统 / 中间件 / API），
source available under the Weixun Source License 1.0。

## 本版内容

本次发版为 M37：Web 简洁化与收尾。自 0.36.0-m36 以来的改动：

### Web 简洁化（核心）

- **两种模式**：医院模式（默认）/ 工程师模式。医院模式只做审计与导报告，
  增加设备、改参数等管理功能收进工程师模式。
- **「审计对象」一页**：数据库 / 操作系统 / 中间件 / 业务接口合并为一页，
  不再按类型分四个入口。
- **首页先告诉用户「现在该做什么」**；问题按对象看，不按事实包看；
  报告页一张表看各对象最新报告。
- **复检对比结论一句话**、规则 ID 换问题名称；管理页拆成标签；
  全站文案与术语统一；医院模式 Playwright 冒烟。

### 修正与收尾

- 复检对比「上次 / 本次」颠倒修正；事实包列表只返回 100 条的问题修正。
- 服务端接口 httptest 覆盖；超级令牌有效期（缺省 90 天、最长 365 天）
  与来源限制；清理旧 MySQL 迁移；CI 加 gofmt 与前端类型检查。
- 审核发现的偏差修复：令牌迁移回填修正与 fail closed、报告页按快照计数、
  医院模式可读名称、业务接口报告按医院过滤、复检候选单个失败时跳过等。

### 评估轮次一等记录（口径修复）

- 评估轮次正式落库：快速连评不再并成一轮，干净重评（0 问题）也有轮次记录；
  报告汇总按最新轮次号统计，不再靠时间聚类推断。
- 同秒连生两份报告撞主键 500 已修复（报告 ID 后缀改纳秒）。
- 老数据启动时回填轮次号（聚类口径，历史轮次真实边界不可恢复）；
  已存报告快照不改写。

## 升级说明

- 平台库自动迁移（014 令牌有效期回填、015 修正、016 评估轮次表与回填），
  无需手工操作。
- 已生成的历史报告为快照，汇总口径不回改；新报告按轮次号汇总。
- 阶段 4 未进本版：医疗行业条款号仍待合规人员对照原文核对
  （medical-draft.yaml 保持 draft，默认不进报告）；HIS / LIS / PACS
  厂商模板仍为草稿，须实施人员按现场核对。
- 已知后续：干净重评后问题列表视图仍显示上一轮问题，彻底修复需
  findings 接口返回最新轮次号，将在后续版本处理。
