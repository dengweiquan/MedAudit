# MedAudit 0.36.0-m36

医疗系统权限审计平台（数据库 / 操作系统 / 中间件 / API），
source available under the Weixun Source License 1.0。

## 本版内容

本次发版将 M35 与 M36 合为一次发出。M36 的主题是**从一次性审计到持续服务**：
报告直接对照合规条款，平台自己按周期复检，权限一有新增就提醒。

### 合规与报告

- **合规条款逐条判定**：Word 报告新增「合规条款逐条判定」章，按条款逐条写
  满足 / 不满足 / 无法判定 / 不涉及 / 本平台未检查，并列出依据（对应检查项与本次
  结果，基线放行的标明）。内置等保 2.0（GB/T 22239-2019）第三级「安全计算环境」
  23 条。
- **医疗行业条款框架（草稿）**：整理《医疗卫生机构网络安全管理办法》与
  GB/T 39725-2020 中账号权限、身份鉴别、传输加密、加固相关要求 10 条要点。
  条款号尚待核对原文，默认不进报告；核实后放入 `/etc/medaudit/compliance/`
  覆盖即启用。站点也可按同格式新增院内制度等框架。`ma comp` 查看启用状态。

### 持续监测

- **定期自动复检**：对象级开启（管理页或 `ma schedon`），到期平台自动审计、
  自动套用本院基线、生成报告；失败次日重试。开启的对象口令以证据密钥
  AES-256-GCM 加密存库，仅执行时解密，关闭即删除；未开启的对象口令仍不落库。
- **权限新增告警**：每个新事实包与同对象上次审计比对，新增授权、角色或账号即
  告警；复检失败也告警。工作台顶部显示，`MEDAUDIT_ALERT_WEBHOOK` 可推送企业
  微信/钉钉群。`ma alertls` / `ma alertack`。
- **复检到期提醒**：工作台「该复检了」与 `ma due`，周期 `MEDAUDIT_AUDIT_CYCLE_DAYS`
  （缺省 30 天）。

### 实施提速

- **基线模板**：数据库内置账号模板（Oracle、MySQL 8.0、SQL Server、PostgreSQL，
  已核实）与 HIS / LIS / PACS 厂商账号模板（草稿，账号为占位、套用时必填）。基线
  页或 `ma tpluse` 一键套用并重评；现场核实的模板放 `/etc/medaudit/baseline-templates/`。
- **M35 问题判定卡**：问题详情按「结论 / 原因 / 怎么改 / 基线屏蔽」顺序展示，内嵌
  单条修复脚本（`GET /api/v1/findings/{id}/fix`）；在线评估默认自动套用本院基线
  （`-b` 指定、`-B` 裸评不变）；`db.oracle.any_privilege` 不再把 DBA 角色本身判为
  问题（规则版本 1→2）。

### 平台自身安全与工程

- **平台操作日志**：所有写操作与文件下载（含登录成功/失败、定期复检）记录操作人、
  时间、来源 IP、结果，不记口令；哈希链防篡改，一键清场不清。管理页可查看与校验，
  `ma oplog` / `ma oplogchk`（被改动退出码 2）。
- **规则元数据单一来源**：`rulesets/*.yaml` 由内置规则生成并在测试中逐字校验；
  补齐至 65 条，修正 3 条停留在旧版本的元数据，新增 `compliance` 字段。
- **CI**：推送与 PR 时构建、vet、测试（含 7 个演示事实包的结论快照）、arm64 与
  Windows 采集器交叉编译、前端构建。

## 升级说明

- 平台库自动迁移（011 操作日志、012 告警、013 定期复检），无需手工操作。
- `/etc/medaudit/medaudit.env` 新增可选项（安装包模板已附注释）：
  `MEDAUDIT_AUDIT_CYCLE_DAYS`、`MEDAUDIT_ALERT_WEBHOOK`、`MEDAUDIT_COMPLIANCE_DIR`、
  `MEDAUDIT_COMPLIANCE_ENABLE`、`MEDAUDIT_BASELINE_TEMPLATE_DIR`。已有配置文件不会
  被覆盖，按需手工添加。
- 定期自动复检依赖证据密钥 `MEDAUDIT_EVIDENCE_KEY`；更换密钥后需重新保存各对象口令。
- 已生成的历史报告为快照，不含逐条判定章；重新导出即有。
