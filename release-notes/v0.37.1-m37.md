# MedAudit 0.37.1-m37

source available under the Weixun Source License 1.0。

## 本版内容

本次发版为 M37 线上的修复版。自 0.37.0-m37 以来的改动：

### 问题列表视图按轮次号取最新一轮（PR #11）

- 新增 `GET /api/v1/findings/latest-run`：返回包的最新轮次号与该轮问题数；
  干净重评（0 问题）也有轮次行，故最新轮次返回新轮次号 + count 0，
  问题列表不再显示上一轮的 stale FAIL。
- `GET /api/v1/findings` 返回结构不动（ma CLI 在用）；工作台、审计对象、
  复检对比、问题页五处调用方改传轮次号；轮次接口失败（旧服务端）或无轮次时
  回退旧口径，兼容旧服务端与老数据。

### 医疗框架条款号对照《办法》公开全文初填（PR #12）

- `medical-draft.yaml`：10 条控制中 8 条填了《医疗卫生机构网络安全管理办法》
  （国卫规划发〔2022〕29号）条款号（直接：医疗-03、04、06、09；
  相关：医疗-01、05、07、10；医疗-02、08 在《办法》中无直接条款故留空）。
- `status` 保持 `draft`，默认不进报告，**本版报告行为不变**。

## 升级说明

- 本版无新数据库迁移，平台库无需手工操作。
- 已生成的历史报告为快照，汇总口径不回改。
- 仍待人工输入（不在本版解决）：GB/T 39725-2020 条款号（全文为付费标准，
  公开渠道仅见章名，须持标准文本的合规人员填写）；HIS / LIS / PACS
  厂商模板（占位账号须换现场实际账号 + 厂商书面说明）；合规人员最终确认后，
  方可把 medical-draft 的 status 改为 verified（另行版本）。
