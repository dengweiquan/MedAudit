# MedAudit 0.30.0-m30

合版发版：M27–M29 里程碑、Web 全局医院筛选、许可证缺省路径、
工作台顶部合计修复、基线编辑与整条删除。注：本版所含改动此前
已在实验室实例逐一验证并上线，本次发版仅补标签与安装包。

## 安装包（零外部依赖）

- `medaudit_0.30.0+m30-1_amd64.deb` — Debian / Ubuntu：
  `sudo apt install ./medaudit_0.30.0+m30-1_amd64.deb`
- `medaudit-0.30.0-m30.1.x86_64.rpm` — RHEL / Rocky / AlmaLinux / CentOS：
  `sudo dnf install ./medaudit-0.30.0-m30.1.x86_64.rpm`
- `medaudit_0.30.0+m30-1_arm64.deb` — arm64 Debian / Ubuntu
- `medaudit-0.30.0-m30.1.aarch64.rpm` — arm64 RHEL / Rocky / AlmaLinux

安装与本站医院设置同前版（交互安装时提示输入本站医院 ID 与名称；
或事后编辑 `/etc/medaudit/medaudit.env` 再重启服务）。浏览器打开
`http://<服务器>:8080`（初始账号 admin，首登强制改密）。

## 本版内容

- **M27 医院登记与一键清场**：`ma hosls` / `ma hosadd` 补工程师
  动线缺口（资产登记要求医院预先存在）；`ma srvreset` 一键清场
  （备份先行、WIPE 确认，清空全部业务数据并恢复默认管理员，
  本站医院按 env 重登记）。
- **M28 医院删除与 ma 中英双语**：`ma hosrm <id>` 级联删除该医院
  全部数据（本站医院禁删，清场走 srvreset）；`ma` 界面语言随运行
  环境（中文环境显示中文，其他环境显示英文），服务端返回文案
  原样透传。
- **M29 Oracle 11g 兼容**：采集器加版本探针与低版本兼容模板
  （11g 字典缺失的列以等价常量入账，收据标 `+compat`）；19c 金标
  回归不变；支持矩阵 Oracle 11g 改为已验证。
- **Web 全局医院筛选**：管理页选医院后，工作台、数据库、操作系统、
  中间件、业务接口、审计记录、问题、报告、复检对比、关联分析
  跟随该医院过滤；规则页不过滤（启停为本站级）。
- **许可证缺省路径**：由 `/etc/medaudit.license` 改为
  `/etc/medaudit/medaudit.license`（与 medaudit.env 同目录）；
  `MEDAUDIT_LICENSE` 仍可覆盖；旧路径文件需手动移入新路径。
- **工作台顶部合计修复**：选医院时顶部「有问题对象 / 待整改
  FAIL」跟随所选医院（此前算全院总数）。
- **基线编辑与整条删除**：基线表每行可编辑放行项（基线 ID、
  医院、目标锁定，保存整体替换、版本 +1）或删除整条基线
  （已存问题与报告不动，之后的评估不再用它豁免）。
