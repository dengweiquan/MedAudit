# 敏感对象最小闭环（M5-5）

只存对象标识与敏感类别，**不存真实患者数据**。首次闭环优先表级；
列级标记可建，但现有事实为表级粒度，列级授权未采集，报告中显式提示。

## 标记模型

- 位置：资产页（对象页）每数据库资产一行「敏感对象」入口；接口见
  `GET/POST /api/v1/sensitive-labels`、`PUT/DELETE /api/v1/sensitive-labels/{id}`。
- 自然键：医院 / 资产 / 库 / 模式 / 表 / 列（唯一约束）。重复创建幂等：
  同键同类别返回原行（不升版本），同键不同类别更新类别并 version +1。
  改名 = 删后重建；PUT 只改类别。
- 权限：登录会话 + 医院/资产归属校验（资产须归属该医院；非数据库资产
  拒绝）。写操作由操作日志中间件落哈希链日志，注记含标记对象身份。
- 版本：创建 version=1，编辑 +1。报告生成时点快照（含 version）；
  标签改删只影响以后生成的报告，已存报告快照不变义。

## 标识符规范化（写入时）

- 去空白；双引号包裹视为引用标识符（去引号、保留原大小写）。
- Oracle 未引用 → 大写；PG 未引用 → 小写；MySQL/MSSQL 原样保留，
  匹配时不区分大小写（MySQL 表名大小写依赖操作系统文件系统，
  MSSQL 依赖排序规则，通常不区分大小写）。
- MySQL 的模式即库：库名优先，库名为空时用模式名匹配。

## 匹配口径（只用已采集事实，不新增采集模板）

匹配以资产（包）为界：标签只匹配本资产包的事实，跨资产同名表不匹配。

| 库 | broad 授权 | 匹配条件 | 风险 |
|---|---|---|---|
| Oracle | PUBLIC 对象授权 | ora.tab_privs，被授者 PUBLIC，Scope=模式.表 精确匹配 | high |
| Oracle | ANY 表权限 | ora.sys_privs/cdb_sys_privs，权限含 ANY TABLE，SYS 模式排除（数据字典保护），DBA 角色按 M35 豁免（固有管理权限），角色传递只计默认激活角色（非默认需 SET ROLE，不计自动可达）；CDB 通用权限（CONTAINER=ALL）本节只计本包，跨 PDB 可达另行注记 | high（基础规则 medium，对象敏感后升级） |
| PG | PUBLIC 对象授权 | pg.object_privileges，被授者 PUBLIC，库/模式/对象三元组精确匹配；PG 超级用户不受 ACL 限制，其可达性不在授权事实中体现，需另行核查 | high |
| MySQL | 全局数据权限 | Scope `*.*`，权限为 SELECT/INSERT/UPDATE/DELETE，可达全部库表；动态权限（如 CONNECTION_ADMIN）不算数据暴露 | high |
| MySQL | 库级数据权限 | Scope `库.*`，库名匹配标签库（或模式），可达该库全部表；角色传递只计默认角色 | high |
| MSSQL | public 授权 | 事实只到数据库级（对象未采集）：public 授权存在时无法确认是否覆盖该表，列为未确认（unconfirmed），不计暴露、不判安全 | — |

- 豁免：匹配到的授权若被该医院基线放行（被授者/权限/范围与评估口径一致；
  角色传递时角色或用户任一放行即豁免），标 exempt，不计入违规暴露。
  这是「合法豁免」的落点：放行项是操作员的明确意图，不是漏报。
- 列级标记：表级 broad 授权可达该列时仍计暴露（附列级未覆盖注记）；
  无表级 broad 授权时不判安全（列级专属授权事实未覆盖）。
- 事实缺失：包中无授权事实，或采集 PARTIAL，节中注记「缺授权事实
  不等于安全」「暴露面可能低估」，绝不输出「无暴露」装作测过。

## 报告展示

- 快照字段 `sensitive`：labels（快照行：对象/类别/版本/状态
  exposed|no-broad-grant|unconfirmed/注记）、exposures（对象/类型/
  被授者/权限/原始事实 ID/风险/豁免）、notes（全局注记：未标记不等于
  不敏感、缺事实不等于安全等）。
- Web 报告详情页渲染该节；Word 报告同节渲染。旧报告无该字段时不渲染
  （不改写旧报告）。
- 标签变化后重新评估 = 下次报告生成时重新取当前标签快照并重新匹配；
  评估本身（问题清单）不受标签影响，标签只决定报告节内容。

## 已知局限（不在本轮解决）

- MSSQL 对象级事实未采集（查询本身不含对象列），故 MSSQL 只能到
  数据库级未确认；要精确到表需先扩展采集模板。
- PG 角色传递（成员继承）未解析：只有 PUBLIC 与直接授权计入，角色
  授权需另行核查成员关系。
- Oracle CDB 本地权限的容器号与 PDB 名无法对应：本节以包（容器视图）
  为界，跨 PDB 可达只对 CONTAINER=ALL 注记，不做跨资产匹配。
- Oracle 标签库名（PDB 名）无法与事实库名对应（事实不带 PDB 名），
  故 Oracle 匹配不按库名过滤，以资产为界。
